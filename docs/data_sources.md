# Data sources

The WKR company, its product master and its sales are fictional and synthetic.
External context data are associated with public German data sources as documented below. Attribution does not, by itself, establish the provenance of every value in the repository.

| File | Source | License / attribution |
|---|---|---|
| `data/raw/automotive_market_de.csv` – `registrations_total_de`, `registrations_bev` | Kraftfahrt-Bundesamt (KBA), monthly new registrations of passenger cars | Source: Kraftfahrt-Bundesamt, Flensburg, https://www.kba.de. Exact extraction and data vintage not independently verified. |
| `data/raw/automotive_market_de.csv` – `vehicle_production_de` | **TODO: confirm original source.** VDA monthly passenger-car production statistics are the intended reference, but the current values have not been reconciled against VDA releases. | **TODO:** verify source and data vintage before attributing the existing series to VDA. |
| `data/raw/datumlanderferienfeiertage.csv` | Public and school holidays associated with the OpenHolidays API (https://www.openholidaysapi.org), transformed into timing features by `src/wkr_pipeline/calendar_pipeline.py` | OpenHolidays; CC BY 4.0 attribution applies to OpenHolidays data. Confirm provenance of this specific file before claiming it is a direct API export. |
| `data/raw/germany_weekly_weather_features.csv` | Weather features attributed to Deutscher Wetterdienst (DWD), Climate Data Center. The precise station selection, aggregation procedure and extraction version have not been independently verified. | Source attribution: Deutscher Wetterdienst (DWD), https://opendata.dwd.de. Verify the applicable reuse terms for the underlying dataset. |
| `data/forecast/automotive_market_de_forecast_2026.csv` | Model output of `R/forecast_automotive_market_de.R` | Projection, not observed data. |
| `data/master/product_master.csv` | Synthetic, generated by `R/generate_product_master.R` | Synthetic data; no external data license claimed. |

## Provenance note

The existing data files and forecasts are left unchanged. In particular, `vehicle_production_de` is **not** presented as a verified reproduction of VDA monthly figures. Source verification and reconciliation can be completed separately without changing the current project snapshot.
