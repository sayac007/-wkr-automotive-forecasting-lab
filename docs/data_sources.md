# Data provenance and redistribution checklist

The company and its sales/product-master records are fictional and synthetic. External datasets are not represented as synthetic. **Exact original download URLs, licenses, dates and redistribution permissions have not been independently verified for this release.**

| File | Described origin | Action before public redistribution |
|---|---|---|
| `data/raw/germany_weekly_weather_features.csv` | Processed German weather indicators, described in project documentation as DWD-derived | Record the specific DWD dataset/stations, retrieval date, processing method and applicable attribution/license; verify that the processed table is independently redistributable |
| `data/raw/automotive_market_de.csv` | German vehicle production/registration indicators; original publisher not verified | Identify each series and its original publisher (potentially VDA/KBA), source URL, usage terms and any attribution required |
| `data/raw/datumlanderferienfeiertage.csv` | German holiday/school-calendar features; Python generator queries OpenHolidays | Identify whether this committed CSV was generated from OpenHolidays or a separate legacy source; document API attribution/license and the feature transformations |
| `data/forecast/automotive_market_de_forecast_2026.csv` | Model-generated automotive market forecast | Document generating script and distinguish projections from observed series |
| `data/master/product_master.csv` | Synthetic product master | Generated by `R/generate_product_master.R` |

Useful starting points for source verification: [DWD Open Data](https://opendata.dwd.de/), [KBA](https://www.kba.de/), [VDA](https://www.vda.de/), [OpenHolidays](https://www.openholidaysapi.org/). These links do not themselves establish the provenance or licensing of the committed files.

Do not claim that public availability alone authorizes redistribution. Replace the outstanding items with source-specific evidence before publication.
